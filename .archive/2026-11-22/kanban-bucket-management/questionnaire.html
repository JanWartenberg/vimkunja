Fixed facts & implementation prerequisites
  • A Board is one Kanban View of a Project. Buckets and card positions belong to that View; Tasks and Done are shared.
  • VOA 2.7.0 creates To-Do / Doing / Done. Existing Tasks start in To-Do, including completed Tasks; their Done state stays unchanged.
  • Zero means unlimited. The last Bucket cannot be deleted. Removing a View keeps its Tasks.
  • Compatibility work comes first: reconcile cross-Board Done behavior, detect imported View filters, verify View-deletion cleanup and special-Bucket deletion against disposable VOA databases. No live round trip was run in this research.
  • Preserve other Boards, imported attributes and unsaved Task/Comment drafts. Archived Projects remain read-only. No schema changes. Repeating-task completion continues to require VOA.

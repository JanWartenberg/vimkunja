## Further context

`/` and `n`/`N` were initially deferred while Global Search used `Space+f` and picker navigation. The accepted contract now implements Local Search independently.

## Confirmed design decisions

- Local Search navigates and highlights matches without filtering out nonmatching content.
- Search scope is always the focused Pane. In the Projects Pane, only Project names are searched; Tasks and their content are excluded.
- In the Tasks Pane, search includes Task titles and displayed metadata across all Tasks in the current list or Kanban Board, including off-screen Tasks. Existing filters remain effective; search does not expand the result set.
- A Task match selects that Task and displays it in the Task Detail Pane, including during incremental search. Enter accepts the selection; Esc restores the original Task selection and scroll position. Focus remains in the Tasks Pane.
- A Project match displays that Project's Tasks during incremental search. Enter accepts the Project; Esc restores the original Project/View context, selection and scroll position. Focus remains in the Projects Pane.
- Cancelling Project search with Esc also restores the original fold state. Accepting with Enter keeps branches opened by the search expanded.
- In the Task Detail Pane, search includes all displayed Task fields and the complete Description, including off-screen text. It searches readable text, excluding HTML tags, invisible Link URLs and separately opened Comments.
- `/` starts the search; `n` and `N` navigate matches. Vim remains the interaction reference.
- In the Projects Pane, search includes Projects inside folded branches. Navigating to a match opens its ancestor branches to reveal it.
- Search previews the first matching position while the query is typed, following Vim's `incsearch` model. Enter accepts that position; Esc restores the starting position. Afterwards, `n`/`N` continue navigating matches.
- Match navigation wraps in both directions, following Vim's `wrapscan` model, with brief feedback when crossing the search boundary.
- Case matching follows Vim with `ignorecase` and `smartcase` enabled: lowercase-only queries ignore case; a query containing an uppercase character is case-sensitive. This is an explicit Vim option combination, not Vim's default. Reference: [Vim user manual, 27.1](https://vimhelp.org/usr_27.txt.html#27.1).
- Search supports the agreed Vim pattern subset rather than literal text only; the specification and keybinding reference define its syntax and limits.
- Jan accepted the consolidated proposals on 2026-11-23, including Vim patterns, `?`, counts, shared history and draft/error handling. See the specification for the complete contract.
- `Space h` is the default synonym for `:nohlsearch`. Searchable Help is a required [follow-up](../../../../.scratch/help-search/issues/01-search-help-pane.md).

## Implementation notes — 2026-11-23

- `Space h` was free and is implemented alongside `:nohlsearch` and `:noh`.
- A pure `internal/searchpattern` module translates the documented Vim default-magic subset and rejects unsupported syntax. Patterns with Unicode word assertions evaluate those assertions during ordered matching; other patterns use the standard regexp matcher. Description search uses projection anchors and semantic highlight roles, independent of HTML and wrapping; Opaque occurrences retain atomic navigation but individual paint/counts.
- Local search owns its own origin/preview state. Cancellation invalidates pending View/Task responses and restores navigation/folds. Missing origin metadata is reloaded; delayed preview errors cannot restore over subsequent user actions.
- Project List loading now reads every page so local search can reach the entire current filtered context, matching Overview's existing pagination policy.
- Focused regressions cover case/Unicode/patterns, counts/directions, per-occurrence navigation including Opaque/zero-width matches, fold restoration, stale/failing loads, dirty-draft protection, SQLite read-only behavior, input routing, metadata arrivals and narrow/clipped rendering.
